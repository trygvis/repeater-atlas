.. requirement::
   :id: RA-1046
   :title: Repeater Detail Responsive Layout
   :type: UX
   :status: Implemented
   :verification: Manual responsive layout test

The repeater detail page shall use a two-column content and map layout on wide
screens and a single-column layout on narrow screens.

Rationale
~~~~~~~~~

Repeater details must remain usable on both desktop and mobile devices.

Acceptance Criteria
~~~~~~~~~~~~~~~~~~~

* Wide screens show content and map in two columns.
* Narrow screens show a single-column layout.
* The detail map is shown only when the repeater has coordinates.
