.. requirement::
   :id: RA-1048
   :title: Repeater Detail Related Repeaters
   :type: Functional
   :status: Implemented
   :verification: HTTP integration test

The repeater detail page shall show linked repeaters, a linked network map, and
nearby repeaters when data is available.

Rationale
~~~~~~~~~

Related repeaters help users understand network topology and nearby options.

Acceptance Criteria
~~~~~~~~~~~~~~~~~~~

* Linked repeaters are listed when links exist.
* The linked network map shows connected repeaters when appropriate.
* Nearby repeaters within 50 km are shown and sorted by distance.
* Nearby markers are labeled by call sign.
