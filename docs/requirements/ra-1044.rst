.. requirement::
   :id: RA-1044
   :title: Portable Logbook Generation
   :type: Functional
   :status: Implemented
   :verification: HTTP integration test

The user account page shall let users generate a portable logbook PDF and the
corresponding Typst source.

Rationale
~~~~~~~~~

Portable operation benefits from printable log sheets and reference material.

Acceptance Criteria
~~~~~~~~~~~~~~~~~~~

* Users can submit logbook options to download a PDF.
* Users can submit the same form to download Typst source.
* Generated output is streamed directly without persisting a logbook record.
