.. requirement::
   :id: RA-1029
   :title: CHIRP RX Tone Option
   :type: Functional
   :status: Implemented
   :verification: Export option test

The CHIRP CSV exporter shall support an option that controls whether RX tone
data is included.

Rationale
~~~~~~~~~

Some radio programming workflows only need TX tone data.

Acceptance Criteria
~~~~~~~~~~~~~~~~~~~

* When RX tone export is enabled, RX tone data can be emitted.
* When RX tone export is disabled, only TX tone data or no tone is emitted.
