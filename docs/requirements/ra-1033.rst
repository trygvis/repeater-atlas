RA-1033: Map Side Pane
----------------------

The map page shall provide a side pane beside the map for header content,
nearest repeaters, and repeater details.

Rationale
~~~~~~~~~

Users should be able to inspect map-related information without leaving the map.

Acceptance Criteria
~~~~~~~~~~~~~~~~~~~

* The side pane is placed beside the map.
* The pane body can contain the site header.
* The pane body can show nearest repeaters and selected repeater details.
