.. requirement::
   :id: RA-1039
   :title: Map Login Access
   :type: Functional
   :status: Implemented
   :verification: UI test

The map page shall provide quick access to the login flow.

Rationale
~~~~~~~~~

Editors and administrators may start from the public map page before logging in.

Acceptance Criteria
~~~~~~~~~~~~~~~~~~~

* The map page contains a login action.
* The login action is available without leaving the map page first.
* The login action navigates to the login flow.
