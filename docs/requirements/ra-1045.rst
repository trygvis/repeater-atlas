.. requirement::
   :id: RA-1045
   :title: Repeater Detail Route
   :type: Functional
   :status: Implemented
   :verification: HTTP integration test

The application shall render a public repeater detail page for a repeater call
sign at ``/{call_sign}``.

Rationale
~~~~~~~~~

Each repeater needs a stable public page with complete details.

Acceptance Criteria
~~~~~~~~~~~~~~~~~~~

* A repeater call sign resolves to the repeater detail page.
* Call signs are uppercased before lookup.
* The page is readable without authentication.
