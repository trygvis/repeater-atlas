.. requirement::
   :id: RA-1037
   :title: Map Viewport Persistence
   :type: Functional
   :status: Implemented
   :verification: UI test

The map page shall store the current viewport after movement and restore it on a
later visit.

Rationale
~~~~~~~~~

Users should return to the same map area they were viewing previously.

Acceptance Criteria
~~~~~~~~~~~~~~~~~~~

* Map movement stores center and zoom client-side.
* A saved viewport is restored on page load.
* Query parameters for ``lat``, ``lon``, and ``zoom`` take priority when present.
