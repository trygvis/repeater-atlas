RA-1002: Mobile-Friendly Layout
-------------------------------

The application shall provide layouts that are usable on mobile screens without
horizontal scrolling.

Rationale
~~~~~~~~~

Repeater directory users commonly access the site from phones while mobile or
portable.

Acceptance Criteria
~~~~~~~~~~~~~~~~~~~

* Public pages fit narrow viewports.
* Primary navigation and actions remain usable on mobile screens.
* Content does not require horizontal scrolling on small screens.
